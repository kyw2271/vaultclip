# Changelog

## 1.1.0 — 2026-09-13

- Add Korean and English locale catalogs and localized extension descriptions.
- Select UI language from Chrome with Korean fallback; allow an explicit language choice saved locally.
- Localize UI, progress messages, extension-defined errors and labels in newly generated Markdown notes.
- Preserve original page text, existing local files and settings.
- Refresh the folder badge after write access is granted.
- Add runtime coverage and actual Chrome screenshots in both languages.

No additional permissions, host permissions, remote code or external data transmission were introduced. Translation catalogs are loaded from packaged chrome-extension:// URLs.
