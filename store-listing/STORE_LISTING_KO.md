# VaultClip 1.1.0 — KO

VaultClip은 현재 웹페이지를 사용자가 선택한 로컬 폴더에 Markdown 노트와 PDF로 함께 저장합니다. Obsidian 등 Markdown 기반 Vault에서 사용할 수 있습니다.

주요 기능
• 저장 시간, 페이지 제목, 간단한 발췌 요약을 담은 Markdown 노트
• 현재 렌더링된 웹페이지의 PDF 아카이브
• PDF 위키 링크 또는 임베드 선택
• Vault 내부 하위 폴더 및 요약 길이 설정
• 한국어·영어 UI와 Markdown 항목 제목 지원
• 외부 서버 업로드와 회원가입 없이 로컬 처리

사용 방법
1. 일반 HTTP/HTTPS 웹페이지에서 VaultClip을 엽니다.
2. ‘Vault 폴더 선택’을 눌러 저장할 폴더를 선택합니다.
3. 저장 폴더와 요약 길이를 설정합니다.
4. ‘요약 MD + PDF 저장’을 누릅니다.

언어
Chrome의 언어에 따라 한국어 또는 영어가 자동 선택됩니다. 지원하지 않는 언어에서는 한국어가 기본입니다. 팝업의 언어 메뉴에서 한국어와 English를 직접 선택할 수 있으며 선택은 로컬에 저장됩니다. 새 Markdown 노트의 ‘저장 시간’과 ‘요약’ 항목도 선택한 언어를 따릅니다. 웹페이지의 원문과 발췌 요약을 다른 언어로 번역하지는 않습니다.

Markdown은 기본적으로 WebClip 폴더에, PDF는 WebClip/_archive/pdf 폴더에 저장됩니다. 요약은 페이지 설명과 본문을 발췌한 텍스트이며 AI 생성 요약이 아닙니다. PDF에는 페이지의 인쇄 스타일이 적용될 수 있습니다.

개인정보 및 권한
사용자가 저장을 실행한 현재 탭의 제목과 내용을 로컬에서 처리합니다. 페이지 데이터와 파일을 개발자 또는 제3자 서버로 전송하지 않습니다. PDF 생성에는 debugger 권한이 사용되며 현재 탭에 일시적으로 연결해 Page.printToPDF를 실행한 뒤 연결을 해제합니다. Chrome에 디버깅 안내가 표시될 수 있습니다.

Chrome 내부 페이지와 확장 프로그램 실행이 제한된 페이지에서는 사용할 수 없습니다.
VaultClip은 Obsidian의 공식 제품이나 제휴 제품이 아닙니다.

1.1.0 업데이트: 영어 UI, 언어 선택 및 영어 Markdown 항목 제목을 추가했습니다.
