# Chrome Web Store submission checklist

## Before upload
- [x] Set developer contact to `kyw2271@gmail.com` in privacy files.
- [ ] Host `privacy-policy.html` at a public HTTPS URL (GitHub Pages is sufficient).
- [ ] Test the extension in a clean Chrome profile.
- [ ] Confirm the selected Vault folder is writable.
- [ ] Confirm Markdown and PDF are created correctly.
- [ ] Confirm debugger connection is detached after each save.

## Developer Dashboard
- [x] Chrome Web Store developer account registered (confirmed by publisher).
- [ ] Add new item.
- [ ] Upload `vaultclip-cws-v1.0.0.zip`.
- [ ] Store listing: paste `STORE_LISTING_KO.md` or English version.
- [ ] Category: Productivity.
- [ ] Upload `assets/store-icon-128.png`.
- [ ] Upload `assets/screenshot-1-1280x800.png` (replace with a real Chrome screenshot before public launch if preferred).
- [ ] Upload `assets/small-promo-440x280.png`.
- [ ] Privacy practices: paste `PERMISSION_JUSTIFICATIONS.md` answers.
- [ ] Set privacy policy URL to the hosted policy.
- [ ] Remote code: No.
- [ ] Test instructions: paste `TEST_INSTRUCTIONS.md`.
- [ ] Distribution: start with Unlisted for initial testing, then switch to Public when ready.
- [ ] Submit for review.

## Important
Unlisted, Private, and Public items are all reviewed under the same Chrome Web Store policies.
The `debugger` permission is powerful and may receive additional scrutiny. Keep the store description, in-product disclosure, privacy policy, and reviewer instructions consistent.
