VaultClip 개인정보처리방침

시행일: 2026년 9월 10일

VaultClip은 사용자가 선택한 웹페이지를 사용자가 선택한 로컬 폴더에 Markdown 노트와 PDF 아카이브로 저장하는 Chrome 확장 프로그램입니다.

접근하는 데이터

사용자가 확장 프로그램을 직접 실행할 때만 현재 웹페이지의 내용과 제목, 로컬 폴더 선택 정보 및 확장 프로그램 설정에 접근할 수 있습니다. 사용자의 웹 탐색 활동을 지속적으로 모니터링하지 않습니다.

데이터 이용 목적

현재 웹페이지의 내용을 브라우저 내부에서 처리하여 간단한 발췌 요약과 PDF를 생성하고, 두 파일을 사용자가 선택한 폴더에 저장합니다. 폴더 접근 핸들과 설정은 사용자의 브라우저에 로컬로 저장될 수 있습니다.

데이터 전송 및 공유

VaultClip은 페이지 내용, 웹 탐색 데이터, 파일, 분석 데이터, 원격 측정 데이터 또는 개인정보를 개발자나 제3자 서버로 전송하지 않습니다. 사용자 데이터를 판매하거나 광고에 이용하지 않습니다.

Chrome debugger 권한

debugger 권한은 사용자가 요청한 PDF 자동 생성에만 사용됩니다. 현재 탭에 일시적으로 연결하여 Page.printToPDF를 호출하고, PDF 데이터를 로컬로 받아 저장합니다. PDF 생성 후 연결을 즉시 해제합니다. 이 권한을 네트워크 트래픽 모니터링, 인증 정보 수집 또는 외부 전송에 사용하지 않습니다.

로컬 파일

VaultClip은 사용자가 브라우저의 폴더 선택 창에서 직접 선택하고 접근을 허용한 폴더에만 파일을 저장합니다. 저장된 파일은 사용자가 관리합니다. 사용자가 동기화 폴더를 선택한 경우 해당 폴더의 동기화는 사용자가 사용하는 서비스의 설정에 따릅니다.

데이터 보관 및 삭제

사용자 데이터가 개발자가 관리하는 시스템으로 전송되지 않으므로 개발자는 이를 보관하지 않습니다. 로컬 Markdown 및 PDF 파일은 사용자가 삭제할 때까지 남습니다. 브라우저에 저장된 확장 프로그램 설정은 확장 프로그램 데이터를 삭제하거나 확장 프로그램을 제거하여 삭제할 수 있습니다.

제한적 이용

Chrome API를 통해 얻은 정보는 확장 프로그램의 웹 클리핑 및 로컬 보관 기능을 제공하는 데에만 사용됩니다. 광고, 신용도 판단 또는 기능과 무관한 목적을 위해 전송하지 않습니다.
