VaultClip Privacy Policy

Effective date: 2026-09-10

VaultClip is a local-first Chrome extension that saves a user-selected web page into a user-selected local folder as a Markdown note and PDF archive.

Data the extension accesses

Only when the user explicitly activates the extension, VaultClip may access the active page content and title, plus local folder selection and extension settings. It does not continuously monitor browsing activity.

How data is used

Data is processed locally to extract a compact summary, generate a PDF, and save both files to the folder selected by the user. Folder handles and preferences may be stored locally in the browser.

Data transmission and sharing

VaultClip does not send page content, browsing data, files, analytics, telemetry, or personal information to the developer or any third-party server. It does not sell user data or use it for advertising.

Chrome debugger permission

The debugger permission is used only for user-initiated automatic PDF generation. VaultClip temporarily attaches to the active tab, calls Page.printToPDF, saves the PDF locally, and immediately detaches.

Local files

VaultClip writes only to folders the user explicitly selects. Saved files remain under the user's control.

Data retention

The developer retains no user data because no user data is transmitted to developer-controlled systems. Local files remain until the user deletes them.

Contact

Developer contact: kyw2271@gmail.com

Limited Use

Information received from Chrome APIs is used only to provide the extension's web clipping and local archiving functionality and is not transferred for advertising, creditworthiness, or unrelated purposes.
